See A Real Example

Here is how a basic sentence can become a structured prompt and an understandable topic description.

SIMPLE IDEA
Explain machine learning for my college assignment.

Detailed Prompt

Explain machine learning in a student-friendly manner. Include its definition, working process, supervised, unsupervised and reinforcement learning, common algorithms, real-world applications, advantages, limitations and suitable examples. Use clear headings and finish with a short conclusion.

Impactful Description

Machine learning is a branch of artificial intelligence that allows computers to learn patterns from data. Instead of programming every rule manually, a machine learning system uses data to identify patterns and produce predictions or decisions. It is used in areas such as recommendations, fraud detection and image recognition.
